1. 这是什么

陪伴卡是一张网页版的陪伴卡片，不用下载 App，浏览器打开就能用。卡里住着几位陪伴者：王大伟、小叔、pg、霍青松、mreasonchan（角色线）、mreasonchan（陪伴线），你也可以自己新增陪伴者（见下面第 4 节）。你可以和他们聊天、抽安慰话、掟骰子、转大转盘、定闹钟、记账、记经期、写日记，还能用应用锁管住刷手机的手、用查岗定时自律。

陪伴卡的地址是（建议收藏）：

https://442379129.github.io/companion-card/

先讲清楚三件事：

一、你的数据（记账、经期、日记、聊天记录）只存在你自己手机的浏览器里，不会上传到任何地方，别人看不到。

二、请用 Safari 打开（iPhone 自带的浏览器）。在微信、Muse 这些 App 里面打开，下载功能会失效，锁文件和备份文件都下不下来。

三、Safari、微信内置浏览器、加到主屏幕的图标，存的数据是分开的。请固定用一种方式打开，不然会发现记录“不见了”（其实是存在另一个浏览器里）。换方式时用最底部的备份功能搬家。

2. 懒得看？让 AI 教你

如果这份指南太长、看不懂，或者你就是懒得看：把下面框里的指令复制下来，粘贴到任何一个 AI 聊天里（DeepSeek、ChatGPT、豆包、通义千问、Kimi，哪个都行），然后直接说你想做什么，比如“我想接 DeepSeek 聊天”“应用锁怎么搭”，AI 就会一步一步教你。

复制后，打开你平时用的 AI 聊天，粘贴、发送，再说你想做什么就行。AI 教你的过程中，永远不要把自己的 API 密钥发给它，密钥只填进你自己的手机。

3. 第一次打开：三步上手

  1. 用 Safari 打开卡片。复制地址到 Safari（iPhone 自带的浏览器），不要用微信里点开。打开后点 Safari 底部的「分享」→「添加到主屏幕」，以后点桌面的图标就能直接进。

    小提醒：加到主屏幕后，请固定从主屏幕图标进；如果一会儿用 Safari 标签页、一会儿用主屏幕图标，两边的数据是分开存的，会互相“看不见”。

  2. 挑一位陪伴者。点卡片顶部的圆形头像，打开陪伴者列表，点谁就换成谁。第一次默认是王大伟。换陪伴者后，问候语、安慰话、聊天对象都会跟着换。
  3. 想聊天的话，先接 API。聊天功能要用你自己的 AI 服务密钥（见下面第 5 节）。不想聊天也完全没关系：安慰话、骰子、转盘、闹钟、记账、经期、日记这些功能不用密钥，直接就能用。

4. 切换陪伴者 · 改人设 · 换头像

卡片顶部右上角有一个圆形头像，那是陪伴者的头像，也是切换的入口。

切换陪伴者

  1. 点顶部的圆形头像，打开陪伴者列表。
  2. 列表里每一行是一位陪伴者，有头像、名字和一句简介。现在正在陪你那位会标着「✓ 而家係佢」。
  3. 点一下想换的那位，整张卡就换成他：问候语、欢迎词、安慰话、聊天记录都会换成他的。每个陪伴者的聊天记录是分开存的，换来换去不会丢。

mreasonchan 有两位，列表里是分开的两行：

mreasonchan（角色线）是 Daddy 同小朋友的亲密关系，mreasonchan（陪伴线）是歌手 Eason 同歌迷的偶像粉丝关系，没有感情线。点哪行就换成哪位，各自的聊天记录和改过的人设分开存，头像共用一张。

改人设（觉得他不像？自己改）

列表里每一位陪伴者都可以改人设——预设的、你自创的、复制出来的都行，改完只存在你自己手机上，不影响别人。预设和复制出来的还能随时恢复；自创的没有预设可恢复，改了就是改了。

  1. 打开陪伴者列表，点那位陪伴者旁边的「改人设」。
  2. 打开后会显示他现在的人设全文，你直接在上面改：改说话方式、加习惯、删掉不喜欢的部分，都行。最多 4000 字，下面有字数统计。
  3. 点「保存」，聊天时就会用你改的这版。列表里那位会多一个「已修改」标记。
  4. 想改回去：再点「改人设」→「还原预设」，确认后就恢复成原来的。

注意：改过的人设不会跟着备份文件走。换手机、换浏览器后要重新改一次。

复制陪伴者（预设和改过的都想玩）

想同时玩预设的他和改过人设的他？点那位陪伴者旁边的「复制」，就会多出一位「名字 1.0」，再复制就是 2.0、3.0，以此类推。复制出来的这位有自己独立的聊天记录和人设，你随便改他，预设那位原封不动。复制时会带走他现在的人设（改过就带改过那版）和现在的头像。

  1. 打开陪伴者列表，点那位陪伴者旁边的「复制」。
  2. 列表里多出「名字 1.0」，点他就换成他，聊天记录是空的，从头开始。
  3. 想改复制出来的这位：点他旁边的「改人设」，和上面改人设的步骤一样；点「还原预设」会回到复制时带过来的那版人设。
  4. 不想要了：点他旁边的「删除」，他的对话记录和改过的人设会一起删掉，没有后悔药。预设陪伴者不能删除。

注意：复制出来的陪伴者只存在你自己手机上，换手机、换浏览器后要重新复制一次。

换头像

  1. 打开陪伴者列表，点那位陪伴者旁边的「换头像」。
  2. 从相册选一张照片，会自动裁成方形小图存在你手机上。
  3. 想换回默认头像：点「还原头像」，确认即可。

注意：换过的头像同样只存在你自己手机上，备份文件里不带走。

自创陪伴者

列表底部点「＋ 新增人设」：起个名字，写一段人设描述（比如“一个讲话很温柔的邻居姐姐，喜欢用粤语陪人聊心事，从不骂人”），点「保存呢个人设」。自创的陪伴者可以点旁边的「改人设」改描述，也可以删除（点旁边的「删除」），删除时他的对话记录会一起删掉，没有后悔药。

5. 接入 API：让陪伴者开口说话（详细）

卡里的「同我倾下计」是真人 AI 聊天：你打什么，他立刻回什么。但卡片本身不提供 AI 服务，你需要用你自己的 AI 服务密钥（这叫 BYOK）。密钥只存在你自己手机的浏览器里，聊天花的是你自己账户的钱。

密钥安全，先讲清楚：

API 密钥就像你账户的银行卡密码——谁拿到，谁就能花你账户里的钱。不要用别人的密钥，也不要把自己的密钥发给任何人（包括发给 AI 聊天）。只把它填进你自己手机上的这张卡和你自己的快捷指令。

第一步：拿到一把密钥

去你想用的 AI 服务官网注册账号、充值（一般几块钱就能聊很久）、创建密钥。常用的几个：

服务去哪里申请备注
DeepSeekplatform.deepseek.com便宜好用，新手推荐先用它
ChatGPT（OpenAI）platform.openai.com需要国外支付方式
Gemini（Google）aistudio.google.com有免费额度
Claude（Anthropic）console.anthropic.com注意：Claude 官方接口不能发图片、不能用 MCP
中转站按卖家给的教程地址和密钥都由中转站提供

申请好后，把那串以 sk- 开头的密钥复制下来（只显示一次的话，先粘贴到备忘录存好，别弄丢）。

她在用的中转站（邀请链接）

如果你不知道用哪家中转站，下面这几家是她自己在用的，点邀请链接注册就行。用邀请链接注册，有的站会给双方都发额度奖励。

首次使用要先去网站注册、创建 API 密钥：点下面的链接打开网站 → 注册一个账号 → 登录后在网站里找到创建密钥的地方（一般叫“API Keys”“密钥管理”或“令牌”），创建一个密钥 → 把密钥和网站给你的接口地址抄下来，按下面“第二步”填进卡里。有的站要先充值或先领赠送额度才能调用，具体看各站自己的页面。

  • 肖恩：注册链接 — 免费大模型 API，注册即送 7000 额度。邀请活动：每邀请 1 人，双方都得额度奖励；最新前沿预览模型免费领；累计邀请 20 人，送无限量周卡。
  • 舒芙蕾：注册链接
  • 橘子汽水：注册链接
  • 7喜：注册链接
  • 玖时：注册链接
  • 启明星：注册链接

小提醒：中转站质量参差，先小额充值试试，觉得稳再多充。邀请奖励规则以各站页面写的为准。

第二步：填进卡里

  1. 在卡里找到「同我倾下计」区，点「收起设定 / 展开设定」打开设置区。
  2. 「AI 服务」下拉里选你用的服务（DeepSeek、ChatGPT、Gemini、Claude、自订 / 中转站）。选好后，「接口地址」那格会自动填好，不用你动手：
    • DeepSeek：https://api.deepseek.com
    • ChatGPT：https://api.openai.com/v1
    • Gemini：https://generativelanguage.googleapis.com/v1beta/openai
    • Claude：https://api.anthropic.com/v1
    • 中转站：手动填对方给你的地址。

    中转站最常见的坑：很多中转站给你的地址本身没有 /v1，要自己在末尾加上 /v1 才连得上，例如 https://xxx.com/v1。没加就会一直连不上。

  3. 「API 锁匙」那格，粘贴你自己的密钥。
  4. 点「拉取模型」：卡会去问对方有哪些模型，拉回来后在「用边个模型」下拉里选一个（DeepSeek 一般选 deepseek-chat）。拉不到也没关系，直接在「手动输入模型名」那格手填模型名——手动这格有字，就会优先用手动这格，所以手填和下拉不要同时留着不同的名字。
  5. 点「保存设定」。然后在输入框打字、点「發送」，他就会回你了。

多组设定：存几套，随时换

设置区顶部「已存设定」可以存好几组不同的服务和模型：点「新增一组设定」会复制当前这组，你改好名字和内容、保存，就多了一组。以后点哪一行，就立刻换成那组，不用重新填。城市和 MCP 设置是所有组共用的，不用逐组设。

聊天时还能做什么

  • 发图片 / 发文件：点输入框左边的「＋」，选图片或文字档案（txt、md、csv 这类），每条消息最多 4 个附件。图片要模型会看图才行；Claude 官方接口发不了图片，会直接拒绝并提示你。
  • 换聊天背景：设置区「聊天背景」有 6 个预设颜色，还能「自定图片」用自己的照片当背景（只换聊天窗的底，气泡不受影响）。
  • 填城市看天气：设置区「你喺边度」填一次城市（例如“北京”），以后每次聊天前卡会自己去查一次实时天气，他就能跟你聊你那边的冷暖。不用密钥，查不到也不会卡住。
  • 清空对话：点「清空对话」，确认后整段对话删干净，没有后悔药。
  • 引用 / 修改 / 撤回：每条消息下面有个「⋯」，点开能引用这条（引用他或者你自己的都行，发出去时他会知道你在回哪句）、修改他的回复（改完之后对话按改好的版本继续）、撤回这条（撤回后记录里没有了，也不会再发给 AI）。撤回前会再问你一次确认。

让 AI 知道你的近况（可选，默认全关）

聊天设置里有个「让 AI 知道你的近况」区，里面有三个开关，默认全关。开哪个，聊天时就会多附一行那个区的摘要给 AI，让他答得贴心点。

记账：本月在当前账本花了多少、最大头是哪类（只算支出，只算账本自己的货币）。

经期：离下次经期预计还有几天（按你记的记录算，和经期区那个预测是同一个）。

日记：最近一篇日记是什么时候写的、还有最近的日记里出现最多的那个词。

摘要是在你手机上算好才发的，不是把整份记录发过去。日记那行尤其注意：只发日期和出现最多的那个词，日记内容一个字都不会发。开关下面有一行预览，打开就能看到实际会发什么，先看清楚再决定开不开。

注意：开着的摘要会跟每条消息一起发给你选的那家 AI 服务。天气是公开数据，这三样是你自己的私事——开之前想清楚，不想让 AI 知道就别开，随时可以关掉。

聊不了？先查这几处

  • 接口地址对不对（中转站有没有加 /v1）。
  • 密钥有没有粘全、有没有多出空格。
  • 模型名对不对（手动那格是不是留了旧名字）。
  • 账户里还有没有余额。
  • 出错时聊天区下面会有一行灰色小字，写的是接口返回的真正原因，照着那句去查。

6. 接入 MCP：让他帮你办事（详细）

MCP 是一种“工具接口”：接好之后，陪伴者聊天时不只能陪你说话，还能顺手帮你做事——比如帮你点一份麦当劳、查一下地图。先说清楚：MCP 只支持 OpenAI 兼容格式的服务（DeepSeek、ChatGPT、中转站），用 Claude 官方接口时开不了 MCP。

三个现成的服务：点一下，填个 Token 就能用

在「同我倾下计」设置区找到「MCP 工具」，下面有三个预设按钮。点一个，地址会自动填好，你再按提示拿到 Token / Key 填进去、保存就行。

（1）麦当劳

  1. 点「麦当劳」按钮，地址自动填好（https://mcp.mcd.cn）。
  2. 去 open.mcd.cn，用手机号登录，申请你自己的 Token。
  3. 把 Token 粘贴到表单的「Token」格，点「保存呢个服务」。
  4. 聊天时跟他说想吃什么，他会帮你查、帮你下单。订单详情和支付链接会返回来，你自己点链接去付款，AI 不碰钱。

Token 会过期。过期后聊天调用工具时会报 401 错误，重新去 open.mcd.cn 申请一个新的、粘贴替换就行，不是卡坏了。

（2）瑞幸

  1. 点「瑞幸」按钮，地址自动填好（https://gwmcp.lkcoffee.com/order/user/mcp）。
  2. 去 open.lkcoffee.com，用手机号登录拿 Token。
  3. 粘贴到「Token」格，保存。

瑞幸的 Token 大约 30 天有效，过期要重新拿。还有，这个服务只做到店自取，不能外卖。

（3）高德地图

  1. 点「高德」按钮，地址自动填好（https://mcp.amap.com/mcp?key=）。
  2. 去高德开放平台申请一个 Web 服务 Key。
  3. 把 Key 接在地址 key= 后面（地址最后变成 ...mcp?key=你申请的Key），「Token」格留空，保存。

加其他服务

  1. 点「新增 MCP」，填三样：服务名（自己起个好认的）、服务地址（必须是 https 开头）、Token。
  2. 有的服务把 Key 放在地址里（像高德那样），Token 就可以留空。
  3. 点「保存呢个服务」。加好后会出现在列表里，可以开关、可以删除（删除前会先问你确认）。

用起来是什么样

  • 聊天时他会自己判断要不要调用工具，你不用下特殊指令，正常说话就行。
  • 凡是会产生实际动作的操作（如下单），会先弹一张确认卡，写明要做什么，必须你亲手点确认才会执行，不会擅自行动。
  • Token 只存在你自己手机的浏览器里，发消息时经接口转过去用，不会被存下来。备份文件里也不含 Token，换手机要重新填。
  • 如果启用了 MCP 服务、但一个工具都加载不到，聊天会直接报错，而不是悄悄当没这回事——这时先查 Token 有没有过期、地址有没有填错。

7. 应用锁：刷手机时拉你一把（详细）

应用锁是帮你管住刷手机的手的：你定好要锁哪些 App、锁多久，时间之内一打开那些 App，就会弹出陪伴者现写的一句话提醒，再弹回陪伴卡。讲清楚：这是软锁，不是铁闸——你再点一次照样进得去，它只是给你一个停下来、想一想的机会。

应用锁只适用于 iPhone（iOS），要用 iOS 的「快捷指令」和「日历」。安卓用不了。

整件事分四部分，缺一不可：① 建一个叫 AppLock 的日历 → ② 搭一条快捷指令 → ③ 建一个自动化 → ④ 在卡里生成锁文件并导入日历。下面一步步来，跟着截屏做。

顺便说一句：这里没有现成的快捷指令链接可以一键添加——原版快捷指令的作者注明了禁二传（不让往外传），所以只能按下面四部分一步步自己搭，搭出来的就是你自己的。

第一部分：新建 AppLock 日历

  1. 打开 iPhone 的「日历」App，点底部中间的「日历」按钮（或左下角“日历”），打开日历列表。
  2. 点「添加日历」（或左下角「添加」→「添加日历」），名字写 AppLock，一个字都不能差，颜色随你。
  3. 保存。这个日历以后专门放锁事件，不要把锁事件加到你平时用的日常日历里。

第二部分：搭快捷指令（照着截屏，一步步加动作）

打开 iPhone 的「快捷指令」App，点右上角「＋」新建一条快捷指令。下面每个动作都是在搜索框里搜名字、点一下加进来。动作名按你的系统语言可能不同，下面同时写上简体和繁体。

  1. 加「获取当前 App」（繁体：取得目前 App）。
  2. 加「设定变量」（繁体：設定變數）：把变量命名为「文本」，值选上一步的「目前的 App」。
  3. 加「查找日历日程」（繁体：尋找日曆行程）：过滤条件设三条——「开始日期」为「最近 1 日」、「结束日期」在「未来 1 日」、「日历」是「AppLock」。
  1. 加「重复」（繁体：重複）：对上一步找到的每个日历行程重复。
  2. 在重复里面加「获取日历日程的详细信息」：在搜索框里搜「详细信息」（繁体搜「詳細」两个字），认准带日历图标（上面写着 12）的那个；也可以在动作库里点 App 分类 →「日历」，在里面找。注意：直接搜「标题」是搜不到它的。加上后它还不是「取得标题」的样子——点一下它里面的「日历日程」，改成「重复项目」（繁体：重複項目），再点「详细信息」改成「标题」，这时它才会变成「从重复项目取得标题」（繁体：從重複項目取得標題）。
  3. 加「设定变量」（繁体：設定變數）：把变量命名为「锁标题」（繁体字面也是「锁标题」），值选上一步的「标题」。
  4. 加「如果」：条件设为「锁标题」「包含」「文本」（文本选第 2 步那个变量）。
  5. 在「如果」里面加「获取 URL 内容」（繁体：取得 URL 內容）。
  1. 点开「获取 URL 内容」这步，展开填好：
    • 网址填（前后不要多任何符号，千万别把反引号 ` 拷进去，会变成 %60 导致接口认不出）：
    https://ixybgwvppukutcawkhxe.supabase.co/functions/v1/david-chat/lockline
    • 「方式」选 POST；「标题」那行留空，什么都不填。
    • 「请求正文」（繁体：要求內文）选 JSON，点「加入新字段」逐个加 6 个字段，值照下面填：
      • provider：填 openai（DeepSeek、ChatGPT、中转站都填这个；Claude 官方接口这里不支持）
      • baseUrl：填你聊天设置里那个接口地址，例如 https://api.deepseek.com
      • apiKey：填你自己的 API 密钥
      • model：填你用的模型名，例如 deepseek-chat
      • personaId：填陪伴者的 id——王大伟填 david，小叔填 xiaoshu，pg 填 pg，霍青松填 qingsong，mreasonchan（角色线）填 mreasonchan，mreasonchan（陪伴线）填 mreasonchan2
      • app：值不要打字，点进去选变量，选第 2 步那个「文本」变量
  1. 加「获取词典值」（繁体：取得詞典值）：在上一步的结果里取 reply 这个字段的值。
  2. 加「显示通知」（繁体：顯示通知）：通知内容选上一步取到的「词典值」。标题可以留空。

    通知消失太快看不清？再加一个「显示提示」（繁体：顯示提示），内容同样选「词典值」。这个弹窗会一直停在屏幕上等你按「好」，看完再弹回卡片，肯定看得到。

  3. 加「打开 URL」（繁体：打開 URL）：填陪伴卡的网址 https://442379129.github.io/companion-card/，这样被锁的 App 一打开，就会弹回卡片。
  4. 加「停止此快捷指令」（繁体：停止此捷徑）。
  5. 「如果」下面的「否则」留空，什么都不用加。最后「结束如果」「结束重复」是自动带上的，不用管。

搭完给这条快捷指令起个名字，例如“app-lock（陪伴卡）”。可以先点右下角的播放键手动跑一次试试：有反应就说明搭对了。

第三部分：建自动化（打开 App 时自动跑）

  1. 在「快捷指令」App 里点底部「自动化」，点右上角「＋」→ 选「App」触发（新版 iOS 里叫「App 打开时」）。
  2. 点「选择」App，把你要锁的 App 全部勾上（例如抖音、小红书），这一步千万别漏：只建了触发条件、没选 App，等于没触发过。
  3. 选「已打开」时运行；打开「立即运行」，不要选“运行时询问”。
  4. 下一步，动作选「运行快捷指令」，选你第二部分搭好的那条。
  5. 保存。这个自动化平时什么都不做，只有当 AppLock 日历里有正在生效的锁事件、你又打开了被锁的 App 时，才会弹提醒。

第四部分：在卡里生成锁文件

  1. 用 Safari 打开陪伴卡，找到「应用锁小工具」区。
  2. 在「要锁边啲 App」里填 App 名，多个用英文逗号隔开（例如 抖音,小红书）。名字必须和系统里显示的叫法一模一样，写错一个字都认不到（例如 B 站要写「哔哩哔哩」，不要写 B 站）。下面有常用 App 的快捷小圆点，点一下就自动填好。
  3. 选锁多久（30 分钟到 8 小时，或自己填小时数，最多 24 小时）。
  4. 点「生成锁文件」，会下载一个日历文件。打开这个文件，导入时一定要选 AppLock 那个日历，加错日历锁就不生效。
  5. 想提前解锁：去日历里删掉那条锁事件，立刻就开。

锁不生效？按顺序查

  • 日历名是不是 exactly AppLock？
  • 锁事件的标题里有没有那个 App 的名字？
  • 自动化是不是「立即运行」？触发条件里有没有选中要锁的 App？
  • 锁事件的时间是不是已经过了？过期的锁不会生效。
  • 快捷指令里的接口网址末尾有没有多出 %60 或别的符号？必须正好停在 lockline。
  • 手动点播放键有反应、但打开 App 没反应：多半是自动化触发条件抽风了（iOS 自己的毛病）。删掉那个自动化，重新建一个一模一样的（不要复制旧的），必要时重启手机，再试自动打开 App。

8. 查岗：定时来看看你在干什么（详细）

查岗是这样的：到你定的时间，他先问你一声“现在可以截屏吗？”——你点好，他才截一张屏发给 AI 看图，然后回你一句通知，告诉你他觉得你在干什么（刷视频、学习、聊天这类大类）。

隐私的事，先讲清楚：

一、截屏前一定会先问你。不方便就点「取消」，不会偷偷截，这条是死线。

二、截图只是过路：接口不保存、不记录，看完就散，不会留任何东西。

三、模型只会讲你在做什么大类，绝不会复述你屏幕上的具体文字、号码、密码或聊天内容。

四、查岗只适用于 iPhone（iOS），要用「快捷指令」，安卓用不了。

五、你选的模型一定要会看图（例如 GPT-4o、Gemini，或中转站里会看图的模型）。纯文字模型看不到图，给了也白给。

现成的快捷指令：点链接直接添加（可跳过下面搭的部分）

不想一步步搭，就点下面的链接，用 Safari 打开，按提示添加，快捷指令直接到你手机上，下面搭的部分不用看了：

添加查岗快捷指令（iCloud 链接）

添加之后，打开这条快捷指令，点开「取得 URL 内容」那步，把请求正文 JSON 里的 4 个占位词换成你自己的：接口地址 换成你的接口地址（例如 https://api.deepseek.com），密钥 换成你自己的 API 密钥，模型 换成一个会看图的模型名（例如 GPT-4o、Gemini），人物 换成陪伴者的 id（王大伟填 david，小叔填 xiaoshu，pg 填 pg，霍青松填 qingsong，mreasonchan（角色线）填 mreasonchan，mreasonchan（陪伴线）填 mreasonchan2）。provider、mime 和 image 不用动。

时间要自己定：这条快捷指令自带定点触发，时间是 23:30，那是她自定的。添加之后，把触发时间改成你自己喜欢的就行——不用删，不用新建，也不用去「自动化」里另建，触发就包含在这条快捷指令里。不要照搬她的时间。隐私那几条在上面，添加前先看一眼。

搭快捷指令（照着截屏，一步步加动作）

已经用上面链接添加了现成快捷指令的，这部分直接跳过。下面是给想自己搭的人看的：打开「快捷指令」App，新建一个自动化，触发条件选「特定时间」（繁体：特定時間），定好你想被查岗的钟点。然后按顺序加这些动作：

  1. 加「显示提示」（繁体：顯示提示）：内容写「现在可以截屏吗？」。点「好」就继续，点「取消」整条就停，不用另外加分支。
  2. 加「等待」：等 2 秒，给你收拾一下画面的时间。
  3. 加「截屏」（繁体：拍攝螢幕截圖）：搜“截”字就能找到，选相机图标那个，它会立刻拍下现在的屏幕。不要选错成「取得最新的螢幕截圖」，那是去相册拿旧的那张。
  4. 加「Base64 编码」（繁体：Base64 編碼）：把上一步的截图编码。
  5. 加「获取 URL 内容」（繁体：取得 URL 內容）：网址填下面这个（前后不要多任何符号）： 
    https://ixybgwvppukutcawkhxe.supabase.co/functions/v1/david-chat/checkin
    方式选 POST，「标题」行留空，「请求正文」（繁体：要求內文）选 JSON，逐个加 7 个字段：
    • provider：填 openai（Claude 官方接口这里不支持）
    • baseUrl：填你聊天设置里的接口地址
    • apiKey：填你自己的 API 密钥
    • model：填一个会看图的模型名
    • personaId：填陪伴者的 id（david / xiaoshu / pg / qingsong / mreasonchan 角色线 / mreasonchan2 陪伴线）
    • mime：填 image/png
    • image：值不要打字，点进去选变量，选上一步的「已 Base64 编码」结果

    不用自己背：卡里「查岗」区有个「查岗配置」，会把你聊天设置里保存好的前 5 个字段显示出来，照着抄就行，还能一键复制。

  6. 加「获取词典值」（繁体：取得詞典值）：取 reply 这个字段。
  7. 加「显示通知」（繁体：顯示通知）：内容选上一步的「词典值」。搞定——到点他就会来敲门。

第一次运行时 iOS 可能会弹权限出来问你，点「始终允许」就行，之后就不用每次批了。

想用日历日程来触发

卡里「查岗」区有个「查岗日程生成器」：选好日子和时间，点「生成查岗日程」，下载一个 .ics 文件加到日历里。日程标题固定是「你在干什么」，里面带一个 5 分钟前的提醒。自动化那边配合一个触发条件，筛日历里标题包含「你在干什么」的事件。

两个容易踩的坑：

一、.ics 日程本身不是触发器，必须同时建一个「特定时间」自动化，日程 + 自动化两个齐了才行。

二、日程里那个 5 分钟前的提醒，必须在导入时还是未来时间——如果生成时定的时间太近，提醒时间已经过了，就永远不会弹。

查岗没反应？

  • 先手动点播放键跑一次：有内容，说明快捷指令本身没问题，问题在自动化触发条件上——删掉自动化重建一个（不要复制），必要时重启手机。
  • 检查模型会不会看图，纯文字模型看不到图。
  • 检查 7 个字段有没有漏，image 有没有选对「已 Base64 编码」那个变量。

9. 其他分区怎么用

从上往下，每个分区是干什么的、怎么用：

搜寻 / 联网搜寻

「搜寻」是在整张卡里找东西：打关键字，会帮你找安慰话、每日一句、转盘选项和每个分区，点结果就直接跳过去。「联网搜寻」是搜外面的：打字后点链接，会用浏览器打开必应（Bing）的搜索结果。

撳开就揽下（安慰话）

先选你现在的心情（好攰 / 好委屈 / 冇动力 / 就係唔开心），再抽一句安慰话。卡顶还有每日一句和按时段变化的问候语，都会跟着当前陪伴者换口吻。

掟骰仔 / 决定骰 / 大转盘

「掟骰仔」：选掟几粒，点数自动加好。「决定骰」：把纠结的选项写进去，骰子帮你拍板，选项可以自己改。「大转盘」：把选项写进去，转到哪个就是哪个，不许反悔。

闹钟 · 倒计时

定好时间，到点弹窗加响铃，可以贪睡 5 分钟。可以导入自己的 MP3 当铃声（只在这次打开期间有效）。倒计时和番茄钟也在这一区。闹钟区有个「屏幕常亮」开关，打开后屏幕不会自动暗下去、计时就不会被冻住——但要注意：手机锁屏或切到后台时，iPhone 会冻结网页计时，这是系统限制，卡改不了。

唞下气（呼吸）

跟着圈圈的节奏呼吸：吸气 4 秒、停一停、慢慢呼出。放空一下用的。

经期记录

来了就记一笔，记得越多，下次预测越准。快来之前 3 天，卡顶会提前提醒你。数据只存在你自己手机上。

记账

记收入和支出，可以分多个账本、多种货币，支出分类很细。还能设存款目标，往里存钱、取钱。每一笔都可以删改。

日记手帐 · 悄悄话

写字、加照片、录音都可以，一篇一篇存着，写完点「收好呢篇」。日记只存在你自己手机里，不会发给任何人。想搬去别的手机，靠备份功能。录音和选音频要在 Safari 里打开卡片才能用，不要用微信内置浏览器。

悬浮导航球

屏幕上那个小圆球，点开是功能导览，点哪个分区就跳到哪个分区，不用自己一直往下划。

10. 备份与搬家

卡片最底部是「备份同搬家」区。换手机、换浏览器、换打开方式之前，先在这里导出备份，不然记录就没了。

  1. 导出：在旧的那边点「导出备份」，会下载一个 JSON 文件，收好它（里面是你自己的记录，不要到处传）。
  2. 导入：在新的那边点「导入」，选回这个文件，确认后现在的记录会被备份里的全部盖过。

备份里有什么、没有什么：

有：经期记录、账本和收支、存款目标、日记（连照片和录音一起）。

没有：API 密钥、聊天记录、改过的人设和头像、MCP 的 Token、聊天背景图片。这些换地方后要重新设置。

还有：下载备份文件要用 Safari 打开卡片；在微信、Muse 里打开是下不到的。也不要用 Safari 无痕浏览模式打开卡片，那样关掉后设置就存不住。

11. 声音：朗读和语音输入

聊天区每条回复旁边都有一个喇叭键，点一下，陪伴者就把那句读出来给你听；输入框旁边有个 🎤 键，点一下说话，讲完再点一下就停，转好的文字会填进输入框，你看过没问题再发送。两样都要在聊天设置里的「声音」区接好声音服务才能用。

接哪个服务

MiniMax 和 ElevenLabs 两家都支持，选一家就行，两家都接好、随时换也行。钥匙是你自己的，只存在你自己手机上，备份不会带走。

MiniMax：去 MiniMax 开放平台申请 API 密钥。注意地址分国际版和国内版：国际版用 https://api.minimax.io，国内版用 https://api.minimaxi.com——用哪个地址，就要用在那边申请的钥匙，混用会报 login fail。Group ID 那个格子一般留空，只有国内版用克隆声音时才需要填。声音在下拉里选，有 20 把现成的；你自己克隆、捏出来的声，把 voice_id 填进「手动输入 voice_id」那格，手动填的优先。

ElevenLabs：去 elevenlabs.io 登录，在账号设置里找到 API Key 贴进来。模型一般不用改。点「拉取声音列表」，你账号里的声音就都拉下来了：现成的、你自己捏的、克隆的，分组列在下拉里，选一把就行；或者把 Voice ID 手填进下面那格，手动填的优先。

注意：ElevenLabs 有个规矩要先说清楚——即时克隆和捏出来的声音只属于你自己的账号，别人就算拿到 Voice ID 也用不了；想让别人也能用，要用 Professional 克隆，再通过声音库分享出去。这是他们家的规矩，不是卡的限制。

怎么用

朗读：点回复旁边的「🔊 读」，读完自动停；想中途停，再点一次。一次最多读 1200 个字，表情符号和格式符号会先去掉，读出来不别扭。

朗读时默认会跳过【】、（）、*斜体* 里面的内容（动作、心理、翻译），只读说出口的话；**粗体**和 “…” 默认会读。想改的话，声音设置里「朗讀嗰陣跳過邊啲」有五个开关，逐个选跳过还是照读，改完立即生效。显示的文字不受影响，变的只是读出来的声音。

语音输入：点输入框旁边的 🎤 开始录音，讲完再点一次停下（最长 2 分钟，到点自动停）。转好的文字会填进输入框，你可以改，改好再点发送。第一次用会问麦克风权限，点允许就行；不给权限就录不了。

注意：朗读时那句回复、转文字时那段录音，会连同你的钥匙一起经卡的接口转去你选的那家声音服务，合成完、转完就没了，接口不存音频也不存钥匙。但有一点和日记不一样：这些内容是要发到服务商服务器上才能出结果的，介意的话就别开。

出问题先看这里

点喇叭没声 / 报错：先看聊天区下面那行灰字，写的是接口回来的真实原因。最常见的是钥匙错了、或者 MiniMax 地址和钥匙不匹配（国际版地址配国内版钥匙就会这样）。

麦克风点不开：浏览器没给麦克风权限。去浏览器设置里允许，再回来试。有些旧浏览器不支持录音，那个 🎤 键会直接藏起来，只能打字。

转出来的文字不对：再讲一次，讲慢点、大声点。周围太吵、或者讲得太快，辨识都会差一些。

12. 常见问题

Q：卡片更新了，我这边还是旧的样子？
A：刷新一下页面，或者关掉重进。网络缓存最多会让你看到 10 分钟前的旧版，等一会儿就好了。卡片地址永远不变，不用重新收藏。

Q：我的记录突然不见了？
A：多半是你换了打开方式（比如平时用主屏幕图标，这次用了 Safari 标签页）。两边数据是分开存的，换回原来那个方式就回来了。以后固定用一种方式打开。

Q：聊天要花钱吗？
A：卡片本身不收费，聊天花的是你自己 AI 账户里的钱。DeepSeek 很便宜，几块钱能聊很久。自己留意账户余额。

Q：我的密钥安全吗？
A：密钥只存在你自己手机的浏览器里，不会上传，备份文件里也不含。但千万别把密钥发给别人，谁拿到谁就能花你的钱。

Q：安卓手机能用吗？
A：卡片本身（聊天、记账、日记这些）安卓浏览器也能打开用。但应用锁和查岗是 iOS 专用的，安卓搭不了。

Q：应用锁 / 查岗突然不灵了，昨天还好好的？
A：iOS 的自动化有时候会自己抽风。先手动跑一次快捷指令：手动有反应、自动没反应，就是触发条件死了——删掉自动化重建一个（不要复制旧的），必要时重启手机。

Q：我真的看不懂，怎么办？
A：回到第 2 节，把那段指令复制下来丢给任何一个 AI，让它一步一步教你。
